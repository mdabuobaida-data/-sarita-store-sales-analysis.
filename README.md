# 📊 Sarita Store – Retail Sales Analysis (Excel)

An Excel-based analysis of a real-world e-commerce order dataset for a fashion retail business, covering **31,000+ orders** placed across  the channels like Amazon, Myntra, Flipkart, Ajio, and Meesho, between January and December 2022.

## 📁 About the Dataset
Each row represents one order line and includes:
- Order ID, Customer ID, Gender, Age, Age Group
- Order Date, Month, Order Status
- Sales Channel (Amazon, Flipkart, Myntra, Ajio, Meesho, and more)
- Product SKU, Category, Size, Quantity
- Amount (INR) and shipping city/state/postal code

## 🔍 What the Workbook Covers
- **Data cleaning**: standardized categories, dates, and channel names
- **Pivot tables**: sales broken down by category, channel, state, and month
- **Category mix**: 8 product categories including Saree, Kurta, Western Dress, Set, Top, and Blouse
- **Geographic reach**: orders shipped to 50 states/union territories across India
- **Business scale**: ₹2.1+ Crore in total order value tracked across the year

## 🛠️ Tools Used
Excel · Pivot Tables · Power Query · Formulas (SUMIFS, COUNTIFS) · Conditional Formatting · Charts

## 📌 Key Takeaways
- **Identified top-performing sales channels and months
- Highlighted best-selling product categories by region
- Practiced structuring messy transactional data into decision-ready summaries**
